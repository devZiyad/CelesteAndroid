# Stage 3b spec
(A) English: confirm CLAUDE.md has the English-only rule (comments, docs, logs, commit messages). As one commit "docs: translate Portuguese comments to English", translate every remaining Portuguese comment and doc string in src/, scripts/, .gitignore and docs/ without changing behavior.
(B) Lifecycle: when the game goes to the background (home, app switch, screen off, call), pause the game (open Celeste's pause menu in a level, as on focus loss on PC), suspend FMOD (mixer suspend) and stop rendering; on return, resume FMOD and keep the game paused. Fix the black screen on return by handling SDL's background/foreground events and recreating the surface/swapchain for both Vulkan and OpenGL ES, with no device-lost crash.
(C) Lock the launcher and game to landscape (sensorLandscape), never portrait.
(D) Install progress: replace "Adapting game / Adapting game to Android" with the real current step and detail, e.g. "Downloading Content/Maps/1-ForsakenCity.bin (312/1217, 640 MB of 1.1 GB)", "Verifying files", "Patching Celeste.exe", "Generating background art". Fix the file counter stuck at 0/1217 so files, bytes and speed update live. When install succeeds, Cancel becomes "Done" and returns to the main screen with Play focused.
(E) Background downloads: run the Steam download and install in a foreground service (foregroundServiceType dataSync, required permissions, notification channel) with a progress notification (percent, Cancel action), holding a Wi-Fi lock and partial wake lock, so it continues when the app is backgrounded, the screen is off or the launcher is swiped from recents. If killed or the network drops, resume automatically when possible. Reopening the app shows live progress. On completion the notification says the game is ready. Don't otherwise change the download engine (speed is already near the user's 30 Mbit/s line).
(F) Autoplay port setting (default on), in launcher Port Settings and in-game Options > PORT: when the game is ready, opening the app boots straight into the game. Android Back stays the game's normal pause/back key. Celeste's title-screen Exit and a new "Exit to launcher" pause-menu item return to the launcher main screen, and returning this way does not autoplay again in that session.
(G) Replace the import-saves button with a "Saves" screen with Import and Export. Export writes the save files (0.celeste etc. and settings) to a folder or .zip picked with Android's file picker. Import validates files, backs up current saves first, then overwrites.
(H) Remove the "Update from Steam" button under Play; add "Check for updates" to the launcher's Port Settings only, never the in-game PORT section.
(I) Steam account section in launcher Port Settings only: show the signed-in account name, "Sign out" (end session, revoke the refresh token where possible, delete it from Keystore and storage) and "Switch account" (sign out, then open login). Sign-out keeps game files and saves; Check for updates then asks to sign in. An account without ownership or family-share access gets a clear message and the existing install is kept.
(J) Sign-in screen: remove the "Open in Steam app" button and its QR-link launching code (the Steam app can't approve a login from a link on the same phone). Offer username/password with Steam Guard (push approval in the Steam app, or a typed code) as the default, and the QR code for scanning with the Steam app on another device as the second option.
